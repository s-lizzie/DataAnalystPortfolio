# Системный анализ Сервиса управления процессом внутреннего обучения сотрудников компании
Проект является выпускной работой для курса Системный аналитик от компании PROMO-IT и состоит из двух частей: 
1) Документ о концепции и границах проекта 
2) Спецификация, которая содержит следующие разделы: 
* перечень бизнес-процессов
* основной бизнес-процесс в нотации BPMN
* реестр вариантов использования
* диаграмму вариантов использования 
* сценарии вариантов использования
* функциональные требования
* нефункциональные требования
* модель данных
* диаграммы последовательности
* методы API
* декомпозицию задач для разработки
